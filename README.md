# ELVNOR — Under Construction

A lightweight static landing page built with HTML and CSS.

## Files
- `index.html` — page content and metadata
- `style.css` — layout and responsive styling
- `images/elvnor-hero.webp` — cropped visual based on the approved concept

## Before publishing
1. Replace each `href="#"` social link in `index.html` with the correct official profile URL.
2. Remove any social platform that ELVNOR does not use.
3. Review `Est. 2025` in the page if you want a different establishment year.
4. Check the page on desktop and mobile.

## Publish with GitHub Pages
1. Create a public GitHub repository named `elvnor-website`.
2. Upload all files and folders in this package (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the published URL to appear in Settings → Pages.
7. In **Custom domain**, enter `elvnor.com` and save.
8. In GoDaddy DNS, add the records GitHub Pages tells you to use. Do not remove MX/TXT records required by Titan email.
9. Once DNS is correct, enable **Enforce HTTPS** in GitHub Pages.

Google Fonts are loaded from Google Fonts; if unavailable, the page falls back to system serif/sans-serif fonts.
